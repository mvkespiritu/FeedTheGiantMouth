# Feed The Giant Mouth

Roblox project scaffold for Feed The Giant Mouth.

## Getting Started

Install the project tools with the manager you use locally:

```bash
aftman install
# or
rokit install
```

Start Rojo while editing in Roblox Studio:

```bash
rojo serve
```

Build a local place file:

```bash
rojo build -o "FeedTheGiantMouth.rbxlx"
```
